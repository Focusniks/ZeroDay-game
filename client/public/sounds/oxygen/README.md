# System sounds (Oxygen)

WAV files copied from **KDE Plasma 6 — Oxygen** sound theme (`kde-plasma-6-oxygen_e75754107b_VSTHEMES-ORG`, vsthemes.org).  
They are shipped under `client/public/sounds/oxygen/` so all players get the same assets.

Playback is triggered from `client/src/lib/osSounds.ts` (windows, dialogs, login/logout, empty trash).
