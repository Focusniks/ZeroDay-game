# Breeze-style place icons (desktop + file manager)

SVGs here mirror the **same shapes/colors** as the inline «Nautilus» icons in `FilesApp` (KDE/GNOME-style blues) plus a **trash** icon in the same spirit.

If you use a full **Breeze Chameleon Dark** pack locally, you can replace these files with your theme’s `places/22/` or `places/48/` equivalents (e.g. `folder.svg`, `computer.svg`, `user-trash.svg`) — keep the filenames so paths in the app stay valid.

Bundled extras used by the in-game file manager sidebar: `document-recent.svg`, `user-home.svg`, `drive-harddisk.svg`, `media-eject.svg`.
