# Изменения в проекте ZeroDay Game

## Дата: 21 марта 2026

### 📋 Обзор изменений

В данном документе описаны все внесённые изменения в проект ZeroDay Game для улучшения браузера Zero Browser и мессенджера Zerogram.

## 🔗 1. Обновление доменных имён сайтов

### Изменения
Все сайты в браузере Zero Browser получили реалистичные доменные имена:

| Тип сайта | Старый URL | Новый URL |
|-----------|------------|-----------|
| **Мессенджер** | `zeroday://messenger` | `https://zerogram.com` |
| **Криптокошелек** | `zeroday://crypto` | `https://cryptowallet.network` |
| **Хостинги** | `zeroday://hosting/*` | `https://*.network` |
| **Провайдеры** | `zeroday://isp/*` | `https://*.network` |

### Хостинг провайдеры (.network):
- `https://cloudpro.network` - Профессиональный хостинг
- `https://fasthost.network` - Быстрый хостинг
- `https://securehost.network` - Безопасный хостинг
- `https://budgethost.network` - Бюджетный хостинг

### Интернет провайдеры (.network):
- `https://freenet.network` - Бесплатный провайдер
- `https://speedmax.network` - Высокоскоростной провайдер
- `https://homenet.network` - Домашний интернет
- `https://fiberoptic.network` - Оптоволоконный интернет

### Файлы:
- `client/src/components/browser/ZeroBrowser.tsx` - обновлены SYSTEM_PAGES и BROWSER_DOMAINS
- `backend/migrations/010_update_site_domains.sql` - миграция для обновления URL в БД
- `backend/migrations/011_seed_browser_sites.sql` - seed-данные для новых сайтов

## 🔍 2. Улучшение поиска в браузере

### Реализованные функции

#### Полнотекстовый поиск
- Поиск по названию сайта
- Поиск по описанию
- Поиск по категории
- Поиск по URL

#### Система релевантности
```typescript
// Веса для различных совпадений:
- Точное совпадение в названии: +100
- Название начинается с запроса: +50
- Название содержит запрос: +30
- Описание содержит запрос: +10
- Категория содержит запрос: +15
- Системные сайты (бонус): +20
```

#### Сортировка результатов
Результаты поиска сортируются по релевантности (от наиболее подходящих к наименее).

### Файлы:
- `client/src/components/browser/ZeroBrowser.tsx` - обновлена функция `searchResults`

## 📡 3. Проверка подключения к сети

### Реализация
Все сайты теперь требуют подключения к сети для доступа. При отсутствии соединения:

1. **Для внешних сайтов** (хостинги, провайдеры, криптокошелек, мессенджер):
   - Показывается экран с ошибкой "Нет подключения к сети"
   - Иконка спутника 📡
   - Сообщение о необходимости подключения

2. **Для системных страниц** (home, search, bookmarks, settings):
   - Доступны офлайн

3. **При попытке навигации**:
   - Показывается уведомление "Нет подключения к интернету"
   - Навигация блокируется

### Файлы:
- `client/src/components/browser/ZeroBrowser.tsx` - обновлена функция `navigateTo` и рендеринг страниц

## 💬 4. Улучшение мессенджера Zerogram

### 4.1 Поиск контактов

#### Улучшения:
- **Уменьшена задержка поиска** с 600мс до 500мс для более быстрого отклика
- **Фильтрация результатов** - исключается текущий пользователь из результатов
- **Обработка ошибок** - улучшена обработка ошибок поиска
- **Валидация** - минимальная длина запроса 2 символа
- **Отображение статуса** - показывается количество найденных пользователей

#### UI улучшения:
- Подсветка выбранного пользователя
- Отображение аватара и имени
- Показ messenger_id (@username)
- Кнопка отправки запроса в друзья

### 4.2 Добавление контактов в друзья

#### Функционал:
- Отправка запроса в друзья через `SendFriendRequest`
- Получение уведомлений о запросах
- Принятие/отклонение запросов
- Автоматическое добавление в контакты при принятии

#### Обработчики:
```typescript
handleAddFriend(messengerId: string) // Отправка запроса
handleRequestRespond(requestId, accept) // Ответ на запрос
handleRemoveContact(contactUserId) // Удаление контакта
```

### 4.3 Создание групповых чатов

#### Новый компонент: `CreateGroupChatModal`

##### Функционал:
- **Выбор участников**: минимум 2 контакта
- **Название группы**: до 50 символов
- **Поиск контактов**: фильтрация по имени/messenger_id
- **Визуальная индикация**: подсчёт выбранных участников
- **Статус создания**: анимация загрузки, успех/ошибка

##### UI элементы:
- Модальное окно с градиентным заголовком
- Список контактов с чекбоксами
- Счётчик выбранных участников
- Кнопка сброса выбора
- Поиск по контактам
- Валидация формы

##### Обработчик:
```typescript
handleCreateGroup(userIds: string[], name: string)
```

Отправляет WebSocket сообщение:
```json
{
  "type": "CreateConversation",
  "user_ids": ["uuid1", "uuid2"],
  "is_group": true,
  "name": "Название группы"
}
```

### Файлы:
- `client/src/pages/MessengerPage.tsx` - обновлены:
  - `AddContactModal` - улучшенный поиск
  - `CreateGroupChatModal` - новый компонент
  - `MessengerWeb` - добавлены обработчики и UI

## 🚀 Как применить изменения

### 1. Применение миграций БД
```bash
cd backend
sqlx migrate run
```

### 2. Запуск проекта
```bash
# Из корня проекта
npm run install:all
npm run dev
```

### 3. Проверка функциональности

#### Браузер:
1. Откройте Zero Browser
2. Проверьте поиск по сайтам (введите "хостинг", "мессенджер")
3. Отключите сеть и попробуйте открыть сайт - должна появиться ошибка
4. Проверьте новые домены в адресной строке

#### Мессенджер:
1. Откройте Zerogram (https://zerogram.com)
2. Нажмите кнопку "Добавить контакт" (+)
3. Введите имя пользователя (минимум 2 символа)
4. Отправьте запрос в друзья
5. Нажмите кнопку "Создать группу" (иконка группы)
6. Выберите 2+ контактов, введите название, создайте группу
